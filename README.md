# Encryption-and-decryption-of-files
# Модуль шифрования файлов (AES-256)

Скрипт предназначен для быстрого и безопасного шифрования файлов в указанной директории и всех её подпапках. Для защиты данных используется стойкий алгоритм **AES-256-CBC**.

⚠️ **Внимание:** Скрипт работает по принципу замещения — после успешного создания зашифрованной копии (с расширением `.crp`) оригинальный файл безвозвратно удаляется из системы (`os.remove`).

## 🛠 Требования и установка

Для шифрования используется библиотека `pyAesCrypt`, которая обеспечивает потоковую работу с файлами, позволяя шифровать даже очень тяжелые архивы и видео без перегрузки оперативной памяти.

Установите зависимость через терминал:
pip install pyAesCrypt


⚙️ Как это работает

  Потоковое шифрование: Размер буфера чтения/записи жестко задан на уровне 512 КБ (buffer_size = 512 * 1024), что гарантирует стабильную скорость и низкое потребление RAM.

  Рекурсивный обход папок: Функция walking_by_dirs использует алгоритм поиска в глубину. Она проверяет содержимое директории: если это файл — шифрует, если папка — заходит внутрь и повторяет процесс.

  Безопасность: Исходные файлы удаляются сразу после шифрования, чтобы исключить утечку незащищенных данных.




  Набор скриптов для рекурсивного шифрования и дешифрования данных в указанной директории и всех её подпапках.
